How are the eight metrics calculated?
  • Static · Sign-to-text accuracy: correctly recognized static signs ÷ all evaluated static tests × 100.
  • Static · Text-to-audio accuracy: correct spoken results ÷ static tests with an audio assessment × 100.
  • Static · Average processing time: average time to recognize a static sign, in milliseconds.
  • Static · Classification speed: total decisions ÷ total measured seconds; unit is decisions per second.
  • Dynamic · Landmark tracking accuracy: compare with independently annotated reference landmarks. MediaPipe's own output is not ground truth.
  • Dynamic · Motion-to-text-and-audio accuracy: tests with both correct text and speech ÷ dynamic tests assessed for both × 100.
  • Dynamic · Average motion processing time: average time to extract and classify motion features.
  • Dynamic · Classification speed: total dynamic decisions ÷ total measured dynamic seconds; unit is decisions per second.

For formal research, confirm with your adviser or statistician whether observations are paired before choosing a statistical test.
